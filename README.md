# Moja záložňa – program pre Windows

## ⬇️ [Stiahnuť Moja záložňa pre Windows (MojaZalozna-Setup.exe)](https://github.com/Dionissro/mojazalozna-releases/releases/latest/download/MojaZalozna-Setup.exe)

Kliknutím na odkaz vyššie sa stiahne **najnovšia verzia** inštalačky (asi 110 MB). Iné súbory netreba.

### Inštalácia
1. Spusti stiahnutý súbor **MojaZalozna-Setup.exe** (dvojklik).
2. Ak sa objaví modré okno **„Systém Windows ochránil počítač“**, klikni na **Ďalšie informácie → Spustiť aj tak**.
3. Klikni na **Inštalovať**. Heslo správcu netreba. Program sa objaví na ploche a v ponuke Štart ako **Moja záložňa**.
4. Prihlásenie: **veduci / veduci** – heslo si hneď zmeň v *Editor → Užívateľov*.

### Aktualizácie
Kto už program má, nemusí nič sťahovať – program po spustení sám ponúkne novú verziu (stačí kliknúť **Áno**,
zmluvy, zákazníci a pokladňa ostanú).

### Čo nesťahovať
V zozname súborov pri vydaní sú aj **latest.json** a **Source code (zip / tar.gz)** – tie nepotrebuješ
(latest.json číta program pri hľadaní aktualizácií, zdrojový kód tu nie je).
